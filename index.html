מבוא לתוכנת אילוסטרייטור

תוכנת אילוסטרייטור מחברת אדובי הינה תוכנה ותיקה ומקצועית ביותר המיועדת בעיקר לאיור וציור דיגיטלי. היא מבוססת על וקטור (תוכנה וקטורית) כתוצאה מהיותה תוכנה וקטורית ובגלל יתרונותיה, היא מיועדת בעיקר למטלות כגון עיצוב לוגואים, יצירת אייקונים, עיצוב אלמנטים וגרפיקות גמישות לאפליקציות ואתרים ועיצוב גרפיקות גדולות מימדים כגון שלטים גדולים לחנויות, בניינים, תחנות דלק, שלטי חוצות וכו'. בנוסף, ניתן גם לעצב בה עבודות לדפוס כמו פליירים, כרטיסי ביקור ועוד.

הבדלים בין תוכנות פוטושופ ואילוסטרייטור

מאפיין אילוסטרייטור (Illustrator) פוטושופ (Photoshop)
א. עיקרון עבודה עבודה עם צורות ואיורים (תוכנה וקטורית) עיבוד תמונות, מבוססת על פיקסלים (Pixels)
ב. יתרונות • קבצים קלים יחסית
• אפשר להגדיל אותם מבלי לאבד מהאיכות (ללא פיקסול)		 • תמונות איכותיות ומציאותיות
• שימוש באפקטים איכותיים
ג. חסרונות • ציורים לא מורכבים ולא מציאותיים מספיק (אינה מאפשרת עיבוד פיקסלים כמו ריטוש)
• ציורים "שטוחים", דו-ממדיים או תלת-ממדיים בסיסיים ביותר
• אפקטים פחות איכותיים ומורכבים		 • ככל שהקבצים איכותיים יותר, הם גם כבדים יותר
• הקבצים "מפוקסלים" (מעוותים ומטושטשים) כשמגדילים או מקטינים אותם

מבט-על על ממשק התוכנה

ממשק התוכנה מורכב מהחלקים הבאים: בחירת מרחב העבודה (WORKSPACE), תפריט עליון, סרגל המאפיינים, לשוניות קבצים פתוחים, ארגז הכללים (סרגל כלים שמאלי), משטח העבודה (Artboard), פאנלים / לוחיות בצד ימין, וסרגל תחתון.

אילוסטרייטור – טכניקות, מיומנויות וקיצורי דרך

איך עושים...? דרך הביצוע בתוכנה קיצורי דרך
יצירת קובץ חדש FILE > NEW CTRL + N
פתיחת קובץ / הבאת תמונה FILE > OPEN | הבאת תמונה ישירות: FILE > PLACE CTRL + O
בחירה, הגדלה או סיבוב כלי הבחירה הרגיל (החץ השחור) V
בחירת נקודת עוגן / אלמנט בקבוצה כלי הבחירה הישיר (החץ הלבן) – משמש גם לבחירת תמונה בתוך מסיכת חיתוך A
שמירה על פרופורציות החזקת מקש SHIFT תוך כדי הקטנה או הגדלה SHIFT
בחירה של מספר אלמנטים החזקת מקש SHIFT וסימון, או בחירת הכל במיטבה CTRL + A
העתקה והדבקה EDIT > COPY / EDIT > PASTE CTRL + C / CTRL + V
קיבוץ / ביטול קיבוץ קליק ימני > GROUP / קליק ימני > UNGROUP CTRL + G / CTRL + SHIFT + G
שליחה אחורה/קדימה (Arrange) סימון > קליק ימני > ARRANGE ואפשרויות: SEND TO BACK, SEND BACKWARD, SEND FORWARD CTRL + [ / CTRL + ]
שמירה של קובץ עבודה (פתוח) FILE > SAVE CTRL + S
שמירה של תמונה סגורה FILE > EXPORT > EXPORT AS (לבחור JPG או PNG ולסמן V ב-USE ARTBOARDS!) —
יצירת צורות מלבן (RECTANGLE), עיגול/אליפסה (ELLIPSE), כוכב (STAR), הבזק (FLARE)
• צורת שמש: כלי הכוכב > הקלקה על המסך > הכנסת מספר הקרניים
• צורת משולש: כלי הפוליגון > הקלקה על המסך > הכנסת מספר 3		 —
ביטול / חזרה לשלב אחרון EDIT > UNDO / EDIT > REDO CTRL + Z / CTRL + SHIFT + Z
חזרה ושכפול הפעולה האחרונה חזרה על פעולת השכפול/הזזה האחרונה CTRL + D
קירוב / הרחקת תצוגה (Zoom) כלי הזכוכית המגדלת (אינו משנה את גודל האלמנט, רק את תצוגת המסך) CTRL + + / CTRL + -
שכפול אלמנט מהיר החזקת מקש ALT + גרירת האלמנט הצידה עם החץ השחור ALT + גרירה
מסיכת חיתוך (Clipping Mask) הדבקת תמונה > יצירת צורה מעליה > סימון שניהם > קליק ימני > MAKE CLIPPING MASK (ניתן לסרטט גם ע"י PEN TOOL) —
חיתוך קצוות תמונה / הסתרה סימון > MASK (בתפריט העליון) > התאמת גבולות התמונה עם החץ השחור —
שקיפות סימון > הורדת האטימות ב-OPACITY בתפריט העליון או בלוחית ה-PROPERTIES —
כתיבה כלי הכתב (T) - הצגת פאנל אופציות כתיבה: WINDOW > CHARACTER CTRL + T
מעבר צבע בעזרת פאנל ה-GRADIENT בצד ימין או כניסה לספריות דרך הדוגמיות בפאנל —
הפיכת תמונה לווקטורית סימון > בחירת אפשרות מתוך תפריט ה-IMAGE TRACE בתפריט העליון —
חיתוך צורות (Pathfinder) פאנל ה-PATHFINDER: חיתוך ע"י צורה קדמית (MINUS FRONT), שילוב צורות (UNITE), פירוק (DIVIDE). אפשר לערוך גם ע"י SHAPEBUILDER או SHAPER. SHIFT + CTRL + F9

הנחיות מפורטות לביצוע התוצרים

📇 כרטיס ביקור

להלן שלבי העבודה לכרטיס ביקור:

  1. פתיחת תוכנת אילוסטרייטור.
  2. יצירת קובץ: FILE > NEW | מספר עמודים: 2 (ARTBOARDS) | מידות: 9 * 5 ס"מ.
  3. פתיחת הלוגו: FILE > OPEN.
  4. סימון הלוגו בעזרת כלי הסימון (החץ השחור).
  5. העתקה: CTRL + C.
  6. הדבקה: CTRL + V.
  7. כתיבת הפרטים: כלי הכתב (T).
  8. יצירת צורות לרקע בעזרת מלבן או אליפסה או כלי העט - PEN TOOL.
  9. חיתוך צורות בעזרת ה-PATHFINDER אם צריך.
  10. או הורדת תמונת רקע מאתר PIXABAY.COM והבאתה ע"י FILE > PLACE והדבקתה לתוך צורה (CLIPPING MASK) או יצירת רקע ע"י PATTERN.
  11. הוספת הקסם והיצירתיות שלכם…. ;-)
  12. שמירה של קובץ העבודה: FILE > SAVE.
  13. שמירה של תמונה סגורה: FILE > EXPORT > EXPORT AS.
דוגמת עבודה - כרטיס ביקור מנדלות:

✉️ נייר מכתבים

להלן שלבי העבודה לנייר מכתבים:

  1. פתיחת תוכנת אילוסטרייטור.
  2. יצירת קובץ: FILE > NEW | מידות: 29.7 * 21 ס"מ (A4).
  3. פתיחת עבודה אחרת (כרטיס ביקור למשל…): FILE > OPEN כדי להעתיק ממנה אלמנטים כמו הלוגו למשל..
  4. סימון בעזרת כלי הסימון (החץ השחור).
  5. העתקה: CTRL + C | הדבקה: CTRL + V.
  6. כתיבת הפרטים: כלי הכתב (T).
  7. יצירת צורות לרקע (רק בקצה העליון ו/או התחתון) בעזרת מלבן או אליפסה או כלי העט - PEN TOOL.
  8. שקיפות לאלמנט גרפי האמצע: להוריד את רמת ה-OPACITY בתפריט העליון או בלוחית ה-PROPERTIES.
  9. הוספת הקסם והיצירתיות שלכם…. ;-)
  10. שמירה של קובץ העבודה: FILE > SAVE.
  11. שמירה של תמונה סגורה: FILE > EXPORT > EXPORT AS.

דוגמת עבודה - חשבונית מס מנדלות:

🎁 נייר אריזה

להלן שלבי העבודה לנייר אריזה (Pattern):

  1. פתיחת קובץ העבודה של הלוגו (בפורמט AI) ע"י: FILE > OPEN.
  2. אם הלוגו מקובץ (בגרופ): קליק ימני + UNGROUP.
  3. ביטול סימון: לגעת באזור ריק עם כלי הסימון (החץ השחור).
  4. סימון האלמנט הגרפי הרצוי, בעזרת כלי הסימון (החץ השחור).
  5. העתקה: CTRL + C.
  6. יצירת הקובץ של נייר האריזה: FILE > NEW במידות: איי 4 - 29.7 * 21 ס"מ.
  7. הדבקה: CTRL + V.
  8. הזזת האלמנט בעזרת החץ השחור מחוץ לגבולות הקובץ.
  9. יצירת ההדפס (הפאטרן): FILE > OBJECT > PATTERN > MAKE.
  10. התאמת ההגדרות הרצויות בחלון שנפתח ואישור: ע"י לחיצה על DONE V (ההדפס יעלם… לא להיבהל…).
  11. יצירת רקע ע"י מתיחת מלבן (כלי צורת המלבן).
  12. הטמעת רקע ההדפס: בחירת צורת הרקע המלבנית בעזרת החץ השחור (אם הוא לא מסומנן עדיין..).
  13. פתיחת חלונית הדוגמיות (SWATCHES) ובחירת ההדפס החדש.
  14. הוספת הקסם והיצירתיות שלכם…. ;-)
  15. שמירה של קובץ העבודה: FILE > SAVE.
  16. שמירה של תמונה סגורה: FILE > EXPORT > EXPORT AS.

📢 פלייר

להלן שלבי העבודה לפלייר:

  1. פתיחת תוכנת אילוסטרייטור.
  2. יצירת קובץ: FILE > NEW | מידות: 21 * 14.8 ס"מ.
  3. פתיחת עבודה אחרת (כרטיס ביקור למשל…): FILE > OPEN כדי להעתיק ממנה אלמנטים כמו הלוגו..
  4. סימון הלוגו (ו/או אלמנטים אחרים) בעזרת החץ השחור.
  5. העתקה: CTRL + C | הדבקה: CTRL + V.
  6. הגדלה / הקטנה ע"י כלי הסימון.
  7. כתיבת כותרת וטקסט פרסומי: כלי הכתב (T).
  8. יצירת צורות לרקע בעזרת מלבן או אליפסה או כלי העט - PEN TOOL.
  9. חיתוך צורות בעזרת ה-PATHFINDER אם צריך.

  11. או יצירת רקע ע"י שימוש בהדפס PATTERN.
  12. אפשר לשחק עם שקיפויות ברקע OPACITY.
  13. הוספת אלמנט או דמות מבודדים מתמונה שהורדתם: לבודד בפוטושופ ולשמור כ-PSD ואז לייבא לקובץ העבודה ב-אילוסטרייטור ע"י PLACE.
  14. הוספת הקסם והיצירתיות שלכם…. ;-)
  15. שמירה של קובץ העבודה: FILE > SAVE.
  16. שמירה של תמונה סגורה: FILE > EXPORT > EXPORT AS.
מה צריך להיות בפלייר?
  • • לוגו, צבעים וזהות העסק
  • • כותרת שיווקית גדולה בפונט ומשקל עבה
  • • טקסט שיווקי עם מסר שיווקי כגון פרסום אירוע, פתיחת עסק או סניף, תערוכה, מבצעים…
  • • רקע מעוצב מעניין שקשור למיתוג ולזהות העסק (צורות, תמונת רקע ו/או פאטרן)
  • • שימוש בצורות להבליט חלק מהטקסט, או מהמבצעים (מלבנים, עיגולים, אליפסות, כוכבים, שמש…)
  • • תמונה מבודדת (ויזואל) שקשורה למסר (חוץ מתמונת הרקע אם יש)
  • • פרטי התקשרות עם אייקונים תואמים (רשתות חברתיות…)
